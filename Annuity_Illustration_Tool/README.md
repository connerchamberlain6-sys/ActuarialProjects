# Annuity Illustrative Tool (Excel)

## Project Overview
Developed an Excel-based tool to illustrate annuity payment scenarios and calculate total payments over time based on different plan options and user inputs. The tool allows users to compare payment structures and visualize how different assumptions affect annuity outcomes.

## Tools & Techniques
- Microsoft Excel
- Financial mathematics
- Spreadsheet formulas
- User inputs and scenario analysis
- Data organization and calculation automation

## Functionality
- Calculates annuity payments across multiple plan options.
- Illustrates total payments over the selected payment period.
- Compares different scenarios based on user-selected inputs.
- Summarizes total payments, payment duration, and the age at which payments conclude.

## Purpose
This project demonstrates the application of mathematical concepts to financial calculations and the development of an interactive spreadsheet tool for analyzing and illustrating annuity scenarios.
