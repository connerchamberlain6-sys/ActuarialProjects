# Bodily Injury Claims Analysis (R)

## Project Overview
This project analyzes an auto insurance bodily injury claims dataset using R. The objective was to explore claim characteristics, develop predictive models, and evaluate model performance using regression and decision tree techniques.

## Tools & Techniques
- R
- Data cleaning and preprocessing
- Exploratory data analysis
- Generalized linear models (GLM)
- Decision trees (rpart)
- Model pruning
- Train/test data splitting
- RMSE model evaluation

## Data Preparation
- Removed observations with zero bodily injury and zero total claims.
- Removed observations with zero total claims.
- Created a log-transformed bodily injury variable.
- Split the data into training and testing datasets.

## Modeling
Developed and evaluated multiple models, including:
- Generalized linear models
- GLM with additional interaction terms
- Decision tree models
- Pruned decision tree models

## Results
Compared model performance using Root Mean Squared Error (RMSE) to evaluate predictive accuracy.

The models were evaluated to determine whether more complex approaches improved predictive performance compared with baseline regression models.

## Key Takeaways
This project provided practical experience cleaning insurance data, building statistical models, evaluating predictive performance, and using R for an actuarial data analysis workflow.
